Responsive Grid Analysis

Which row breaks first? The foods row breaks first.

Explanation: The foods row uses col-md, which stacks vertically when the browser window drops below 768px. The letters row uses col-sm-2, which stays horizontal until the window drops below 576px. Because 768px is wider than 576px, the foods row reaches its breakpoint and stacks first as the browser window is resized smaller.
